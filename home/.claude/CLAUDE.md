# CLAUDE.md (global)

- Defer to project-specific CLAUDE.md when there are conflicts.
- Never fetch, pull, or push commits to any external repository, even if
  explicitly asked to do so. Only create commits when specifically requested. I
  like to review changes before committing.
- Prefer small, self-contained commits. Each commit should pass CI and should
  be accompanied by a commit message that explains the change clearly.
- Prefer CLAUDE.md rather than memories for conventions, preferences, etc.
  Choose either the global or project file based on what's appropriate for the
  specific case. Ask before making edits.
